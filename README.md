# RashiVibe — Light Theme Test Build (2026-09-07)

This is a complete static GitHub Pages build for testing a **light warm-ivory / kesari-gold / soft-maroon theme** that is intentionally different from the current dark RashiVibe theme.

Included in this consolidated build:
- High-resolution, tightly cropped RashiVibe logo and hero icon using the same supplied artwork.
- Light theme across homepage, tools, Rashifal pages, forms, profile/login, reports and footer.
- Centered and more visible Sri Yantra behind the homepage icon.
- Working Kundli Milan repair pass, typed-place resolving, clearer errors and PDF flow.
- Profile place suggestions, coordinate → place-name lookup, profile delete, account create/login/delete UI retained.
- Current Kundli, Panchang, Rashifal, Sade Sati, Muhurat, Numerology and Ratna pages retained.

## GitHub Pages
Upload the **contents** of this folder to the root of a new repository and enable GitHub Pages from the repository root.

`firebase-config.js` still needs real Firebase project values before real Phone OTP / Email cloud accounts work.

If the new repository name differs from the previous test repo, update absolute URLs inside `sitemap.xml` after the final repository name is decided.
